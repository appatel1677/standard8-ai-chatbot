# 📚 ધોરણ 3 થી 8 ગુજરાતી માધ્યમ - સ્માર્ટ AI શિક્ષક (Standard 3 to 8 Chatbot)

ગુજરાત રાજ્ય શાળા પાઠ્યપુસ્તક મંડળ (GCERT) અને **DIKSHA App** ના અધિકૃત અભ્યાસક્રમ આધારિત **ધોરણ 3 થી 8 (ગુજરાતી માધ્યમ)** ના તમામ વિષયો માટેનો AI ચેટબોટ.

## ✨ મુખ્ય વિશેષતાઓ
- **ધોરણ 3 થી 8 નો સમાવેશ:** ધોરણ 3, 4, 5, 6, 7 અને 8 ના તમામ વિષયો માટે સંપૂર્ણ સપોર્ટ.
- **તમામ વિષયોનો સમાવેશ:** ગણિત, વિજ્ઞાન, સામાજિક વિજ્ઞાન, ગુજરાતી, અંગ્રેજી, હિન્દી, સંસ્કૃત, વૈદિક ગણિત અને સર્વાંગી શિક્ષણ.
- **DIKSHA અભ્યાસક્રમ અને લાઈવ PDF સપોર્ટ:** દરેક વિષયના પ્રકરણો DIKSHA પોર્ટલ મુજબ ગોઠવેલા છે અને જરૂર મુજબ પ્રકરણની અધિકૃત DIKSHA PDF સીધી AI સાથે જોડીને જવાબ મેળવી શકાય છે.
- **ફોટો / PDF અપલોડ:** કોઈ પણ દાખલા, પ્રશ્ન કે સ્વાધ્યાયનો ફોટો અથવા PDF અપલોડ કરીને સ્ટેપ-બાય-સ્ટેપ ઉકેલ મેળવો.
- **સ્માર્ટ અભ્યાસ બટન્સ:** પ્રકરણનો સારાંશ, સ્વાધ્યાય ઉકેલ, ૫ MCQ ટેસ્ટ, સરળ ઉદાહરણ, નોટ્સ ડાઉનલોડ (PDF/TXT/MD) અને નવી ચેટ.

## 🚀 કેવી રીતે ચલાવવું?
```bash
pip install -r requirements.txt
streamlit run app.py
```

અથવા `.streamlit/secrets.toml` માં `GEMINI_API_KEY = "તમારી_કી"` મૂકીને સીધું ચલાવી શકો છો. બહુવિધ કી માટે `GEMINI_API_KEYS = "key1,key2,key3"` વાપરો.
